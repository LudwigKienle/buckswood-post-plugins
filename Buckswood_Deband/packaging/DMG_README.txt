Buckswood Deband v1.0

1. Quit DaVinci Resolve and other OpenFX hosts.
2. Run Buckswood_Deband_v1.0_Installer.pkg.
3. Restart the host and open the OpenFX browser.
4. Find the effect under Buckswood Restoration.

The macOS installer places the universal plugin in:
/Library/OFX/Plugins/BuckswoodDeband.ofx.bundle

Documentation is included in English and German.
