# Buckswood Post Plugins v2.6.0

This release adds and updates two independent OpenFX tools for DaVinci Resolve.

## Buckswood DeJitter v1.1

- Viewer-native tracking point with pixel-accurate X/Y fine controls.
- Optional texture snapping with a visible requested-to-analysis point guide.
- Single-pass normalized correlation reduces tracking sample work.
- Unchanged or untrusted frames bypass high-quality resampling.
- Universal macOS and Windows x64 builds.

## Buckswood Optics Lab v1.1

- Calibrated alpha-depth controls: invert, near, far, and gamma.
- Rotatable anamorphic axis for bokeh and flare streaks.
- ISO-linked animated sensor grain.
- Inactive stages skip redundant neighborhood, CA, and mapping samples.
- Neutral rendering uses a single source sample.
- Universal macOS and Windows x64 builds.

## Licensed assets

Paid Glass aperture images are not included. Optics Lab can load compatible
images from a folder owned by the licensed user. The macOS disk image includes
a helper that copies those local assets without uploading or redistributing them.

Both plugins are independent implementations and are not affiliated with or
endorsed by Glass, CG Lounge, or Arvid Schneider.
